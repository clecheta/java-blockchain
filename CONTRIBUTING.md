# Contributing to JBlock

Thank you for your interest in contributing to this project.

## Canonical repository

The **canonical source of truth** for this project is GitLab:

- Repository: https://gitlab.com/cleberlecheta/java-blockchain
- Issues: https://gitlab.com/cleberlecheta/java-blockchain/-/issues
- Merge Requests: https://gitlab.com/cleberlecheta/java-blockchain/-/merge_requests

Any GitHub (or other) mirror is a **showcase only**. Please do **not** open pull requests, issues, or discussions there as the official contribution workflow. Contribute exclusively on GitLab.

## How to contribute

1. Open an issue on GitLab to discuss the change (when the change is non-trivial).
2. Fork or branch from the default branch on GitLab.
3. Implement your change with a clear, focused commit history.
4. Open a Merge Request (MR) on GitLab with a clear description of **what** changed and **why**.
5. Ensure the CI pipeline and tests pass.

## Technical expectations

- Run the full test suite locally before submitting: `mvn test`
- Keep changes scoped; prefer small, reviewable MRs
- Match existing code style and project structure
- Include or update tests when you change business or protocol logic
